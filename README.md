# 한Q

[한Q 소개 사이트](https://jungti1234.github.io/hanq/)

**복잡한 설정 없이, 맥의 한영 전환부터 한자 입력까지. Quick하게, 한큐에.**

맥을 쓰면서 익숙한 위치에 한영키가 없어 아쉬웠나요? 한자키는 어디에 있는지, 한자 입력은 어떻게 하는지 찾아본 적은요?

한영 전환키를 눌렀는데 전환이 누락되거나, 첫 글자가 이전 언어로 입력되는 일도 있습니다. 영어로 바꾸고 `hello`를 쳤는데 `ㅎello`가 되어 다시 고치는 불편함까지. 한큐(HanQ)는 이런 **한영키·한자키 사용의 불편함과 전환 씹힘을 줄이기 위해 만든 macOS 메뉴바 앱**입니다.

> 한Q는 현재 베타 단계입니다. 앱과 macOS 환경에 따른 동작을 계속 검증하고 있습니다. 사용 중 겪은 문제를 피드백으로 알려주세요.

## 왜 한Q인가요?

- **간단하게 시작합니다.** 앱을 설치하고 손쉬운 사용 권한을 허용하면 기본 설정으로 사용할 수 있습니다.
- **익숙한 입력 환경을 유지합니다.** macOS 기본 한글 입력과 Apple 한자 후보창을 그대로 사용합니다.
- **작성하던 곳에서 바로 고칩니다.** 영어로 잘못 입력한 글자와 분리된 자모를 다시 입력할 필요 없이 변환합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 한영 전환 | **우측 Command (한영키 매핑)** — 한 번 눌러 한영 전환 |
| 한자 변환 | **우측 Option (한자키 매핑)** — Apple 한자 후보창에서 선택한 한자로 원문을 대체. 한글이 함께 남는 현상도 호환 보정 |
| 전환 언어 (입력 소스) 표시 | 전환한 언어의 **입력 소스 이름을 화면에 잠시 표시** |
| 영타 → 한글 | **우측 Option (한자키 매핑)** — 선택한 영타를 사용하던 한국어 자판 배열에 맞춰 한글로 변환 |
| 자모 합치기 | **우측 Option (한자키 매핑)** — 선택 영역이나 현재 문단의 `ㅇㅏㄴㄴㅕㅇ`을 `안녕`으로 합치기 |
| 자동 실행·메뉴바 상주 | 로그인 시 자동으로 시작해 Dock 아이콘 없이 메뉴바에 상주 |
| 간단한 옵션 제공 | 한영키·한자키·입력 소스 표시·자동 실행 옵션과 **시스템에 연동되는 한/A (Caps Lock) 키 전환 설정** 제공 |

### 외부 키보드 설정

처음 감지한 외부 키보드는 한영키와 한자키로 사용할 키를 차례로 누른 뒤 **저장**합니다. 한 번 저장하면 다음 연결부터 기억한 설정을 사용하며, 내장 키보드는 기존 우측 Command·Option을 사용합니다.

**나중에**를 누르면 안내를 확인한 뒤 설정을 계속하거나 미룰 수 있습니다. 설정을 미루면 키보드에 따라 한영키·한자키가 올바르게 동작하지 않을 수 있습니다. 다시 지정하려면 메뉴바의 **외부 키보드 설정 → 해당 키보드**를 선택하세요. 등록한 키는 해당 기능이 켜져 있는 동안 전용 키로 사용합니다.

오른쪽 Command(Windows·Super)·Option(Alt)·Control·Shift, 언어키와 메뉴 키를 지정할 수 있습니다. 왼쪽 보조키·문자키·스페이스·방향키·F키·Caps Lock·Fn·조합 키는 지정할 수 없습니다. 판정은 macOS가 전달한 키 신호를 기준으로 합니다. 외부 키보드 설정 메뉴는 외부 키보드가 감지될 때만 표시됩니다.

키보드의 연결 방식이나 포트를 바꾸면 다시 확인할 수 있습니다. 일련번호 없는 같은 모델을 같은 포트에 번갈아 연결하면 기존 설정을 공유할 수 있습니다. macOS 또는 다른 키 매핑 도구 때문에 기기·키를 구분할 수 없는 경우에는 등록이 제한됩니다.

## 다른 한영 도구·한글 입력기와 어떻게 다른가요?

도구마다 설정 방식과 지원 범위는 다릅니다. 한Q의 설정 방식과 기존 입력 환경을 유지하는 특징을 비교하면 다음과 같습니다.

| 비교 항목 | 다른 도구에서 필요한 경우 | 한Q의 편리함 |
| --- | --- | --- |
| **한영키·한자키 설정** | 사용할 키와 동작을 직접 지정하거나 매핑 규칙 설정 | 우측 Command·Option에 기본 지정. 외부 키보드는 사용할 키를 한 번씩 눌러 지정 |
| **입력기 등록** | 별도 한글 입력기를 설치하고 입력 소스에 추가·선택 | **기존 macOS 입력기를 그대로 사용** |
| **기존 입력 환경 유지** | 새 입력기의 조합 방식이나 한자 변환 방식에 적응 | **익숙한 기본 한글 입력과 Apple 한자 후보창 유지** |
| **한/A (Caps Lock) 키 전환 설정** | 시스템 설정에서 해당 항목을 찾아 변경 | **한Q 메뉴에서 바로 변경**, 시스템 설정과 연동 |

## 시작하기

[첫 베타 다운로드 · 0.1.0-beta.1](https://github.com/jungti1234/hanq/releases/tag/v0.1.0-beta.1)

이번 베타는 Developer ID 서명·공증 미적용이며, 정식 출시 전 베타 단계에서 적용할 예정입니다.

1. 위 다운로드 페이지의 **Assets**에서 `.dmg` 파일을 내려받아 열고 `HanQ.app`을 **Applications(응용 프로그램)** 폴더로 복사한 뒤 실행합니다.
2. 앱이 열리면 안내 창에서 **손쉬운 사용 설정 열기**를 누릅니다. (최초 실행이 차단되면 아래 **최초 실행이 차단될 때**를 참고합니다.)
3. 시스템 설정의 **개인정보 보호 및 보안 → 손쉬운 사용**에서 한Q를 허용합니다. 목록에 없다면 `+`로 앱을 추가합니다.
4. 권한이 확인되면 안내 창이 닫히고 메뉴바에서 동작합니다. 이후 로그인 시 자동 실행되면 저장된 설정으로 시작합니다.

최초 실행 시 **한영키 사용**, **한자키 사용**, **입력 소스 변경 시 화면에 표시** 설정은 기본값이 ON입니다. **로그인 시 자동 실행**은 최초 실행 때 등록을 시도하며, macOS의 추가 승인이 필요하거나 등록에 실패하면 활성화되지 않을 수 있습니다. 메뉴에서 현재 상태를 확인할 수 있습니다. **한/A (Caps Lock) 키로 입력 소스 전환**은 macOS에 설정된 ON/OFF 상태를 그대로 사용합니다. 이후에는 저장된 설정을 사용합니다.

한국어·영어 입력 소스가 이미 등록되어 있어야 해당 언어로 전환할 수 있습니다.

### 최초 실행이 차단될 때

이 안내는 **Developer ID 서명·공증 미적용 버전**에 해당합니다.

Developer ID 서명·공증이 적용되지 않아 macOS가 앱을 확인할 수 없다는 안내가 나타날 수 있습니다. 출처를 확인한 한Q 설치 파일을 실행하려면, 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 한Q에 대한 **그래도 열기**를 선택하고 확인 절차를 진행하세요. 자세한 절차는 [Apple 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40617/mac)를 참고하세요.

## 사용법

아래 우측 Command·Option 설명은 기본 매핑 기준입니다. 설정한 외부 키보드에서는 각각 지정한 한영키·한자키를 사용합니다.

| 키 | 동작 |
| --- | --- |
| 우측 Command (한영키 매핑) | 한국어 → 영어, 영어 → 한국어, 그 밖의 입력 소스 → 영어 |
| 우측 Option (한자키 매핑) | 선택한 영타를 한글로 변환, 현재 문단·선택 영역의 자모 합치기, 또는 한자 변환 |

메뉴바에서 **한영키 사용**, **한자키 사용**, **입력 소스 변경 시 화면에 표시**, **로그인 시 자동 실행** 설정을 각각 ON/OFF로 변경할 수 있습니다.

우측 Option을 사용하는 기능은 **한자키 사용** 설정이 ON이어야 합니다. 이 설정이 ON이면 우측 Option은 전용 키로 사용하며, 일반 Option 단축키는 좌측 Option을 사용합니다. 보안 입력이 활성화된 동안에는 키 변경 기능이 작동하지 않을 수 있습니다.

### 한영 전환

한국어에서는 마지막으로 사용한 영어 입력 소스로, 영어에서는 마지막 한국어 입력 소스로 전환합니다. 일본어 등 다른 입력 소스에서는 영어로 전환합니다.

한영 전환은 macOS에 등록되어 사용 가능한 입력 소스에서 이루어집니다. 마지막 입력 소스를 사용할 수 없으면 영어는 ABC, 한국어는 두벌식을 우선하며, 없으면 해당 언어의 다른 사용 가능한 입력 소스를 선택합니다. 전환할 언어가 없거나 현재 입력 소스를 읽지 못하면 우측 Command는 원래 동작을 유지합니다.

### 한자 변환

우측 Option (한자키 매핑)을 누르면 분리된 자모를 먼저 합칩니다. 합칠 자모가 없고 Apple 한국어 입력 소스가 선택된 상태라면, 선택한 한글이나 커서 바로 앞에 이어진 한글을 대상으로 한자 후보창을 엽니다. 후보에서 원하는 한자를 선택하세요. 한자 변환은 현재 앱의 입력 상태와 접근성 지원에 따라 동작합니다.

> **영타 → 한글·자모 합치기 공통 안내:** 두 기능은 현재 입력 언어와 관계없이 사용할 수 있으며, ⌘Z로 변환 전 상태로 되돌릴 수 있습니다. 접근성 지원과 실제 실행 취소 동작은 편집기마다 다를 수 있습니다.

### 선택한 영타를 한글로 변환

영문으로 잘못 친 부분을 선택하고 우측 Option (한자키 매핑)을 누르면 한글로 바꿉니다. 선택 영역에 영문 알파벳이 있어야 하며, 공백·탭·줄바꿈은 유지합니다. 한글 등 비ASCII 문자가 섞인 선택 영역에는 영타 변환을 적용하지 않습니다. 선택이 없으면 영타 변환은 실행하지 않습니다.

두벌식 사용 시 `Slackdptj dPrlgkwk`에서 `dptj dPrlgkwk`만 선택하고 우측 Option을 누르면 `Slack에서 얘기하자`가 됩니다. 영어로 남길 단어는 선택에서 제외하세요.

한국어 입력 소스를 사용 중이면 현재 자판 배열을, 영어 등 다른 입력 소스를 사용 중이면 마지막으로 사용한 한국어 자판 배열을 따릅니다. macOS 기본 두벌식·세벌식·세벌식 390을 지원합니다. 한국어 사용 이력이 없거나, 입력 소스·배열을 확인할 수 없거나, 미지원 배열이거나, 자판 자료를 읽을 수 없으면 두벌식으로 변환합니다.

영타는 QWERTY 영문 키 위치를 기준으로 해석합니다. 두벌식에서는 숫자·문장부호를 유지하고, 세벌식에서는 숫자·문장부호 위치의 자모도 해당 배열에 맞춰 변환합니다. 대문자는 Shift를 누른 키에 대응하며, 영어 단어를 사전이나 AI로 자동 판별하지 않습니다.

### 자모 합치기

텍스트를 선택하고 우측 Option을 누르면 선택 영역의 분리된 자모를 왼쪽부터 합칩니다. 예를 들어 `ㅇㅏㄴㄴㅕㅇ! ㅋㅋㅋ`는 `안녕! ㅋㅋㅋ`가 됩니다. 영어·기존 한글·띄어쓰기·줄바꿈·문장부호 그리고 조합할 수 없는 자모는 유지합니다.

선택이 없으면 커서가 있는 문단 전체를 처음부터 끝까지 처리합니다. 문단은 실제 줄바꿈으로 구분하며 화면의 자동 줄바꿈은 경계가 아닙니다. 다른 문단은 건드리지 않습니다. 여러 문단의 자모를 처리하려면 해당 범위를 선택하세요.

### 한/A (Caps Lock) 키로 입력 소스 전환

**한/A (Caps Lock) 키로 입력 소스 전환** 설정을 한Q 메뉴에서 ON/OFF로 변경할 수 있습니다. 시스템 설정 창을 따로 열 필요가 없으며, Caps Lock의 대문자 잠금 기능은 그대로 사용할 수 있습니다.

macOS 설정과 연동되어 처음에는 시스템에 설정된 값을 그대로 표시합니다. 변경한 설정은 시스템 전체에 적용되고 **한Q를 종료해도 유지됩니다.** **한영키 사용** 설정이 ON이고 macOS에서 해당 설정 변경을 지원할 때 사용할 수 있습니다.

## 업데이트

메뉴에서 <strong>업데이트 확인…</strong>을 선택하면 새 버전이 있는지 확인할 수 있습니다. **업데이트 자동 확인**을 켜면 새 버전을 자동으로 확인하며, 설치는 사용자가 선택한 뒤 진행됩니다.

중요한 보안 문제를 해결하기 위해 업데이트가 꼭 필요한 경우에는 안내와 함께 한Q 기능이 일시 중단될 수 있습니다. 이 확인은 자동 확인 설정을 꺼도 이루어집니다. 인터넷에 연결할 수 없거나 확인에 실패하면 계속 사용할 수 있습니다.

업데이트 확인 시 입력한 글자나 클립보드 내용은 전송하지 않습니다.

현재 Developer ID 서명 미적용 버전에서는 업데이트 후 손쉬운 사용 권한을 다시 허용해야 할 수 있습니다. 권한 안내가 계속되면 시스템 설정의 손쉬운 사용 목록에서 기존 한Q를 제거하고 <strong>응용 프로그램 폴더의 <code>HanQ.app</code></strong>을 다시 추가해주세요.

## 사용 중단 및 앱 제거

사용을 중단하려면 메뉴바에서 **로그인 시 자동 실행** 설정을 OFF로 변경한 뒤 **한Q 종료**를 선택하세요. 다시 앱을 실행하기 전까지 한Q의 키 매핑과 텍스트 변환 기능은 동작하지 않습니다.

앱을 제거하려면 위 절차로 종료한 뒤 다음과 같이 진행하세요.

1. Finder에서 `HanQ.app`을 휴지통으로 옮깁니다.
2. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용** 목록에 한Q가 남아 있으면 선택하고 `−` 버튼으로 제거합니다.

한Q에서 변경한 **한/A (Caps Lock) 키로 입력 소스 전환** 설정은 macOS 설정이므로 앱을 제거해도 유지됩니다. 이전 상태로 되돌리려면 앱을 종료하기 전에 해당 설정을 변경하거나, macOS의 키보드 설정에서 변경하세요.

## 문의 및 피드백

메뉴에서 **피드백 남기기…** 항목을 선택하면 브라우저에서 피드백 폼이 열립니다. 앱 버전·빌드번호, macOS 버전, Mac 모델 식별자가 미리 입력되며 내용을 작성한 뒤 직접 제출할 수 있습니다. 그 외 정보는 포함하지 않습니다.
