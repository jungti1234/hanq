# 한Q

[한Q 소개 사이트](https://jungti1234.github.io/hanq/)

**복잡한 설정 없이, 맥의 한영 전환부터 한자 입력까지. Quick하게, 한큐에.**

맥을 쓰면서 익숙한 위치에 한영키가 없어 아쉬웠나요? 한자키는 어디에 있는지, 한자 입력은 어떻게 하는지 찾아본 적은요?

한영 전환키를 눌렀는데 전환이 누락되거나, 첫 글자가 이전 언어로 입력되는 일도 있습니다. 영어로 바꾸고 `hello`를 쳤는데 `ㅎello`가 되어 다시 고치는 불편함까지. 한큐(HanQ)는 이런 **한영키·한자키 사용의 불편함과 전환 씹힘을 줄이기 위해 만든 macOS 메뉴바 앱**입니다.

> 한Q는 현재 베타 단계입니다. 앱과 macOS 환경에 따른 동작을 계속 검증하고 있습니다. 사용 중 겪은 문제를 피드백으로 알려주세요.

## 왜 한Q인가요?

- **간단하게 시작합니다.** 앱을 설치하고 손쉬운 사용 권한을 허용하면 기본 설정으로 사용할 수 있습니다.
- **익숙한 입력 환경을 유지합니다.** macOS 기본 한글 입력과 Apple 한자 후보창을 그대로 사용합니다.
- **작성하던 곳에서 바로 고칩니다.** 영어로 잘못 입력한 글자와 분리된 자모를 다시 입력할 필요 없이 변환합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 한영 전환 | **우측 Command (한영키 매핑)** — 한 번 눌러 한영 전환 |
| 한자 변환 | **우측 Option (한자키 매핑)** — Apple 한자 후보창에서 선택한 한자로 원문을 대체 |
| 전환 언어 (입력 소스) 표시 | 전환한 언어의 **입력 소스 이름을 화면에 잠시 표시** |
| 영타 → 한글 | **우측 Option (한자키 매핑)** — 선택한 영타를 사용하던 한국어 자판 배열에 맞춰 한글로 변환 |
| 자모 합치기 | **우측 Option (한자키 매핑)** — 선택 영역이나 현재 문단의 `ㅇㅏㄴㄴㅕㅇ`을 `안녕`으로 합치기 |
| 자동 실행·메뉴바 상주 | 로그인 시 자동으로 시작해 Dock 아이콘 없이 메뉴바에 상주 |
| 간단한 옵션 제공 | 한영키·한자키·입력 소스 표시·자동 실행 옵션과 **시스템에 연동되는 한/A (Caps Lock) 키 전환 설정** 제공 |

외부 키보드는 호환을 위해 사용할 한영키·한자키를 지정할 수 있습니다.

기본 한국어 입력기의 일부 입력 문제를 보완하는 동작과 적용 조건은 [입력 안정성 보완](#입력-안정성-보완)을 참고하세요.

## 다른 한영 도구·한글 입력기와 어떻게 다른가요?

도구마다 설정 방식과 지원 범위는 다릅니다. 한Q의 설정 방식과 기존 입력 환경을 유지하는 특징을 비교하면 다음과 같습니다.

| 비교 항목 | 다른 도구에서 필요한 경우 | 한Q의 편리함 |
| --- | --- | --- |
| **한영키·한자키 설정** | 사용할 키와 동작을 직접 지정하거나 매핑 규칙 설정 | 우측 Command·Option에 기본 지정. (외부 키보드는 호환을 위해 사용할 키를 한 번씩 눌러 지정) |
| **입력기 등록** | 별도 한글 입력기를 설치하고 입력 소스에 추가·선택 | **기존 macOS 입력기를 그대로 사용** |
| **기존 입력 환경 유지** | 새 입력기의 조합 방식이나 한자 변환 방식에 적응 | **익숙한 기본 한글 입력과 Apple 한자 후보창 유지** |
| **한/A (Caps Lock) 키 전환 설정** | 시스템 설정에서 해당 항목을 찾아 변경 | **한Q 메뉴에서 바로 변경**, 시스템 설정과 연동 |

### 한국어 입력기 지원 대상

한Q의 지원 대상은 Apple이 macOS에서 공식 제공하는 한국어 입력기 전체입니다. 현재 두벌식·세벌식·세벌식 390·공진청 로마자·한컴 로마자를 대상으로 합니다.

## 시작하기

[베타 다운로드](https://github.com/jungti1234/hanq/releases)

현재 베타 배포본은 Developer ID 서명·공증이 적용되지 않았습니다. 정식 출시 시 Developer ID 서명·공증을 적용할 예정입니다. 최초 실행이 차단되면 [아래 안내](#최초-실행이-차단될-때)를 따라주세요.

1. 위 다운로드 페이지의 **Assets**에서 `.dmg` 파일을 내려받아 열고 `HanQ.app`을 **Applications(응용 프로그램)** 폴더로 복사한 뒤 실행합니다.
2. 앱이 열리면 안내 창에서 **손쉬운 사용 설정 열기**를 누릅니다. (최초 실행이 차단되면 아래 **최초 실행이 차단될 때**를 참고합니다.)
3. 시스템 설정의 **개인정보 보호 및 보안 → 손쉬운 사용**에서 한Q를 허용합니다. 목록에 없다면 `+`로 앱을 추가합니다.
4. 권한이 확인되면 안내 창이 닫히고 메뉴바에서 동작합니다. 이후 로그인 시 자동 실행되면 저장된 설정으로 시작합니다.

외부 키보드 사용 시 설정창이 나타나면 사용할 키를 차례로 눌러 저장하세요.

최초 실행 시 **한영키 사용**, **한자키 사용**, **입력 소스 변경 시 화면에 표시** 설정은 기본값이 ON입니다. **로그인 시 자동 실행**은 처음 실행할 때 자동으로 설정하지만, macOS의 추가 승인이 필요하거나 설정에 실패하면 켜지지 않을 수 있습니다. 메뉴에서 현재 상태를 확인하세요. **한/A (Caps Lock) 키로 입력 소스 전환**은 macOS에 설정된 ON/OFF 상태를 그대로 사용합니다. 이후에는 저장된 설정을 사용합니다.

한국어·영어 입력 소스가 이미 등록되어 있어야 해당 언어로 전환할 수 있습니다.

### 최초 실행이 차단될 때

이 안내는 **Developer ID 서명·공증 미적용 버전**에 해당합니다.

Developer ID 서명·공증이 적용되지 않아 macOS가 앱을 확인할 수 없다는 안내가 나타날 수 있습니다. 출처를 확인한 한Q 설치 파일을 실행하려면, 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 한Q에 대한 **그래도 열기**를 선택하고 확인 절차를 진행하세요. 자세한 절차는 [Apple 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40617/mac)를 참고하세요.

## 사용법

아래 우측 Command·Option 설명은 기본 매핑 기준입니다. 설정한 외부 키보드에서는 각각 지정한 한영키·한자키를 사용합니다.

| 키 | 동작 |
| --- | --- |
| 우측 Command (한영키 매핑) | 한국어 → 영어, 영어 → 한국어, 그 밖의 입력 소스 → 영어 |
| 우측 Option (한자키 매핑) | 선택한 영타를 한글로 변환, 현재 문단·선택 영역의 자모 합치기, 또는 한자 변환 |

메뉴바에서 **한영키 사용**, **한자키 사용**, **입력 소스 변경 시 화면에 표시**, **로그인 시 자동 실행** 설정을 각각 ON/OFF로 변경할 수 있습니다.

<strong>진단 및 로그</strong> 부메뉴에서 입력 문제 조사용 로컬 기록을 관리할 수 있습니다.

- <strong>진단 기록 활성화</strong>로 수집을 켜거나 끕니다. 최초에는 꺼져 있으며 설정은 재실행·재부팅 후에도 유지됩니다. 이상이 생기면 <strong>방금 발생한 문제 기록</strong>으로 시점을 표시합니다. 수집을 끄면 문제 기록은 비활성화되지만 기존 기록은 내보낼 수 있습니다.
- <strong>진단 기록 내보내기…</strong>에서 최신순 전체 목록을 스크롤하고 기록을 선택합니다. 약 5개가 보이며 최신 1건이 기본 선택됩니다. 최대 5건까지 선택하고 같은 사건의 전후 기록은 1건으로 셉니다. 선택 개수를 표시하고 5건이면 미선택 체크박스를 비활성화하며 하나를 해제하면 다시 선택할 수 있습니다.
- 미리보기에서 전후 기록·저장 상태를 읽기 쉬운 문구로 확인합니다. ZIP에는 선택한 전후 로그와 저장 상태를 원래 파일명·바이트 그대로 넣습니다. 파싱·집계는 화면에만 적용하며, 화면과 같은 `summary.txt`와 실제 환경값의 `environment.json`을 추가합니다. 앱·macOS·Mac 모델·입력기·관련 기능 설정은 검토 시점의 환경 정보로 모두 포함됩니다.
- 실제 ZIP 크기를 표시하고 용량 제한 검사는 하지 않습니다. <strong>내보내기…</strong>로 원하는 위치에 날짜·시간이 붙은 ZIP을 저장한 뒤 파일을 직접 피드백에 첨부합니다.

자동 보정 시작의 최초 감지 사유와 직전·직후 상태도 기록하며, 기록만으로 입력 누락이나 원인을 확정하지 않습니다. 입력 본문·키 값·클립보드는 저장하지 않습니다. 자동 기록은 최대 64파일·32MiB, 수동 기록은 건수 제한 없이 16MiB 안에서 각각 오래된 사건 묶음부터 순환합니다. 두 종류의 한도는 독립적이며 내보낸 ZIP은 삭제하지 않습니다. 진단 ON에는 추가 CPU·저장 부하가 발생하며 보관 한도는 누적 쓰기량 제한이 아닙니다.

우측 Command를 통한 한영 전환은 **한영키 사용** 설정이 ON이어야 합니다. 이 설정이 ON이면 우측 Command는 한영 전환 전용 키로 사용하며, 일반 Command 단축키는 좌측 Command를 사용합니다.

우측 Option을 사용하는 기능은 **한자키 사용** 설정이 ON이어야 합니다. 이 설정이 ON이면 우측 Option은 전용 키로 사용하며, 일반 Option 단축키는 좌측 Option을 사용합니다. 보안 입력이 활성화된 동안에는 키 변경 기능이 작동하지 않을 수 있습니다.

### 한영 전환

한국어에서는 마지막으로 사용한 영어 입력 소스로, 영어에서는 마지막 한국어 입력 소스로 전환합니다. 일본어 등 다른 입력 소스에서는 영어로 전환합니다.

한영 전환은 macOS에 등록되어 사용 가능한 입력 소스에서 이루어집니다. 마지막 입력 소스를 사용할 수 없으면 영어는 ABC, 한국어는 두벌식을 우선하며, 없으면 해당 언어의 다른 사용 가능한 입력 소스를 선택합니다. 전환할 언어가 없거나 현재 입력 소스를 읽지 못하면 우측 Command는 원래 동작을 유지합니다.

전체 선택 후 한영을 전환할 때는 한글 조합을 확정하고 선택을 유지하도록 처리합니다.

### 한자 변환

우측 Option (한자키 매핑)을 누르면 선택한 영타를 한글로 변환하고, 영타 변환 대상이 아니면 분리된 자모를 합칩니다. 두 변환 모두 적용할 내용이 없고 Apple 한국어 입력 소스가 선택된 상태라면, 선택한 한글이나 커서 바로 앞에 이어진 한글을 대상으로 한자 후보창을 엽니다. 후보에서 원하는 한자를 선택하세요. 한자 변환은 현재 앱의 입력 상태와 접근성 지원에 따라 동작합니다.

기본 사전과 사용자 등록 사전의 후보를 함께 확인하며 원문 한글 항목은 제외합니다. 원문과 다른 후보가 없으면 후보창을 열지 않습니다. 후보 조회나 표시가 실패하면 Apple 입력기의 기존 후보창을 사용하므로 원문 한글 항목이 표시될 수 있습니다. 한글 조합 직후에도 조합을 확정한 뒤 선택한 한자로 대체합니다.

> **영타 → 한글·자모 합치기 공통 안내:** 두 기능은 현재 입력 언어와 관계없이 사용할 수 있으며, ⌘Z로 변환 전 상태로 되돌릴 수 있습니다. 접근성 지원과 실제 실행 취소 동작은 편집기마다 다를 수 있습니다.

### 선택한 영타를 한글로 변환

영문으로 잘못 친 부분을 선택하고 우측 Option (한자키 매핑)을 누르면 한글로 바꿉니다. 영문 알파벳이 포함된 범위에 적용하며, 영문 알파벳·숫자·기본 문장부호·공백·탭·줄바꿈만으로 이루어져 있어야 합니다. 한글·한자·이모지·악센트가 붙은 영문 등이 함께 선택되어 있으면 변환하지 않습니다. 공백·탭·줄바꿈은 유지하며, 선택이 없으면 실행하지 않습니다.

두벌식 사용 시 `Slackdptj dPrlgkwk`에서 `dptj dPrlgkwk`만 선택하고 우측 Option을 누르면 `Slack에서 얘기하자`가 됩니다. 영어로 남길 단어는 선택에서 제외하세요.

한국어 입력 소스를 사용 중이면 현재 자판 배열을, 영어 등 다른 입력 소스를 사용 중이면 마지막으로 사용한 한국어 자판 배열을 따릅니다. 한국어 사용 이력이 없거나 해당 자판 배열을 확인하거나 사용할 수 없으면 두벌식으로 변환합니다.

영타는 QWERTY 영문 키 위치를 기준으로 해석합니다. 두벌식에서는 숫자·문장부호를 유지하고, 세벌식에서는 숫자·문장부호 위치의 자모도 해당 배열에 맞춰 변환합니다. 대문자는 Shift를 누른 키에 대응하며, 영어 단어를 사전이나 AI로 자동 판별하지 않습니다.

### 자모 합치기

텍스트를 선택하고 우측 Option을 누르면 선택 영역의 분리된 자모를 왼쪽부터 합칩니다. 예를 들어 `ㅇㅏㄴㄴㅕㅇ! ㅋㅋㅋ`는 `안녕! ㅋㅋㅋ`가 됩니다. 영어·기존 한글·띄어쓰기·줄바꿈·문장부호 그리고 조합할 수 없는 자모는 유지합니다.

선택이 없으면 커서가 있는 문단 전체를 처음부터 끝까지 처리합니다. 문단은 실제 줄바꿈으로 구분하며 화면의 자동 줄바꿈은 경계가 아닙니다. 다른 문단은 건드리지 않습니다. 여러 문단의 자모를 처리하려면 해당 범위를 선택하세요.

실제 교체는 바뀌는 자모 구간에만 적용해 그 사이의 본문·서식·첨부 이미지를 유지합니다. 여러 구간의 변환은 편집기의 다중 선택과 실제 반영을 확인한 뒤 수행합니다. 필요한 선택을 지원하지 않거나 반영하지 못하면 문단 전체를 덮어쓰지 않고 편집을 중단합니다.

여러 구간을 처리하지 못하는 편집기에서는 합칠 자모 구간 하나만 직접 선택하고 실행하세요.

변환 뒤 커서는 첫 번째 교체 구간 끝에 놓입니다. Undo/Redo의 커서는 편집기의 기본 복원 동작을 따릅니다. 여러 구간을 다시 실행하면 마지막 교체 구간 끝에 놓일 수 있습니다.

### 한/A (Caps Lock) 키로 입력 소스 전환

**한/A (Caps Lock) 키로 입력 소스 전환** 설정을 한Q 메뉴에서 ON/OFF로 변경할 수 있습니다. 시스템 설정 창을 따로 열 필요가 없으며, Caps Lock의 대문자 잠금 기능은 그대로 사용할 수 있습니다.

macOS 설정과 연동되어 처음에는 시스템에 설정된 값을 그대로 표시합니다. 변경한 설정은 시스템 전체에 적용되고 **한Q를 종료해도 유지됩니다.** **한영키 사용** 설정이 ON이고 macOS에서 해당 설정 변경을 지원할 때 사용할 수 있습니다.

### 외부 키보드에서 사용하기

처음 감지한 외부 키보드는 한영키와 한자키로 사용할 키를 차례로 누른 뒤 **저장**합니다. 한 번 저장하면 다음 연결부터 기억한 설정을 사용하며, 내장 키보드는 기존 우측 Command·Option을 사용합니다.

**나중에**를 누르면 안내를 확인한 뒤 설정을 계속하거나 미룰 수 있습니다. 설정을 미루면 키보드에 따라 한영키·한자키가 올바르게 동작하지 않을 수 있습니다. 다시 지정하려면 메뉴바의 **외부 키보드 설정 → 해당 키보드**를 선택하세요. 등록한 키는 해당 기능이 켜져 있는 동안 전용 키로 사용합니다.

오른쪽 Command(Windows·Super)·Option(Alt)·Control·Shift, 언어키와 메뉴 키를 지정할 수 있습니다. 왼쪽 보조키·문자키·스페이스·방향키·F키·Caps Lock·Fn·조합 키는 지정할 수 없습니다. 판정은 macOS가 전달한 키 신호를 기준으로 합니다. 외부 키보드 설정 메뉴는 외부 키보드가 감지될 때만 표시됩니다.

키보드의 연결 방식이나 포트를 바꾸면 다시 확인할 수 있습니다. 일련번호 없는 같은 모델을 같은 포트에 번갈아 연결하면 기존 설정을 공유할 수 있습니다. macOS 또는 다른 키 매핑 도구 때문에 기기·키를 구분할 수 없는 경우에는 등록이 제한됩니다.

## 메뉴바 아이콘이 보이지 않을 때

한Q가 실행 중이어도 Mac의 노치, 메뉴바 공간 부족, 메뉴바 관리 앱의 숨김 설정 때문에 아이콘이 가려질 수 있습니다. 먼저 메뉴바 표시·숨김 설정을 확인하세요.

1. 한Q가 실행 중인 상태에서 `HanQ.app`을 다시 열면 메뉴바 아이콘을 재등록해 복구를 시도합니다. 기존 메뉴와 저장된 아이콘 위치를 유지합니다.
2. 60초 안에 다시 열기를 3회 시도하면 <strong>한Q - 메뉴바 아이콘 안내</strong> 창이 나타납니다. 숨김 설정이 원인이 아닌데도 아이콘이 보이지 않으면 창의 <strong>피드백 남기기…</strong> 버튼으로 제보할 수 있습니다.

메뉴바 항목 누락과 빈 이미지 등은 자동 복구를 시도하며, 화면 구성 변경과 잠자기 복귀에도 다시 등록합니다. macOS나 메뉴바 관리 앱의 숨김 설정은 사용자가 직접 확인해야 하며, 모든 원인의 아이콘 누락이 복구되는 것은 아닙니다.

## 입력 안정성 보완

한Q는 수동 변환·선택·한영 전환의 처리 순서를 확인하고, macOS 기본 한국어 입력기를 사용할 때 발생할 수 있는 일부 입력 문제를 자동으로 보완합니다. 자동 보정은 별도 설정 없이 동작하며, 입력 환경에 따라 적용 여부가 달라질 수 있습니다.

### 수동 변환·선택·한영 전환

영타→한글·자모 합치기 직후에도 첫 한영 전환을 처리합니다. 변환의 선택 반영을 기다리는 동안 누른 전환 요청을 보존하고, 변환 결과를 확인한 뒤 전환·후속 입력을 순서대로 처리합니다.

첫 자음 보정 뒤 전체 선택하거나 한영을 전환할 때도 선택과 입력 순서를 유지하도록 처리합니다. 입력칸의 안내 문구가 사라지거나 커서·선택 반영이 늦는 경우에도 앞선 입력을 확인한 뒤 후속 키를 처리합니다. 텍스트 선택을 제공하는 콤보 상자 입력란도 지원합니다.

### 첫 자음 조합 보정

입력창 밖에서 타이핑을 시작할 때 `ㅈㅏ`처럼 첫 자음·쌍자음이 분리되는 현상을 보완합니다. 특정 앱으로 제한하지 않습니다.

입력기의 응답 지연으로 첫 단어가 분리된 자모로 남는 경우도 보완합니다. 두벌식·세벌식·세벌식 390·공진청 로마자·한컴 로마자의 배열과 조합 규칙을 따르며, 공백으로 단어가 확정된 뒤 원래 입력칸에 입력한 내용이 그대로 남아 있는 경우에만 적용합니다. 권한이나 입력 감시의 일시적 문제가 해소되면 새 입력부터 자동 보정을 재개합니다.

보정 전에 진행 중인 한글 조합을 확정해 자음이 중복되거나 후속 입력이 보류되는 문제를 줄입니다. 삭제 뒤 이미 확정된 한글과 새 자음이 정상적으로 이어지는 입력은 자동 보정하지 않습니다.

### 한국어 입력 불일치 자동 복구

한국어 입력 소스가 선택되어 있는데 영문이 입력되는 현상을 감지해, 현재 한국어 자판 배열에 맞게 복구합니다. 기본 복구는 시스템 전환 단축키 없이 입력 소스를 직접 선택해 다시 적용합니다. 재입력 뒤 한글·분리 자모·영문이 섞이거나 후속 한글 조합이 끊기는 경우에도 실제 입력 이력과 본문·커서가 확인된 구간을 보완합니다.

해당 배열에서 정상적으로 입력되는 영문은 바꾸지 않습니다. 확인된 두벌식 전환과 입력 소스 조회가 잠시 어긋나면 관측 이력을 보존하고 재확인한 뒤 복구를 판단합니다. 사용자가 명시적으로 영어로 전환한 입력은 복구 대상에서 제외합니다.

복구 중 이어서 누른 키는 순서대로 처리합니다. 한Q의 우측 Command·외부 키보드에 지정한 한영키뿐 아니라, macOS의 Caps Lock 한영 전환 설정이 켜져 있을 때의 실제 언어 전환과 메뉴바에서 선택한 입력 소스도 후속 입력에 반영합니다. 입력 메뉴를 취소하면 기존 언어에서 복구를 이어갑니다.

복구가 중단되어 전달하지 못한 입력이 있으면 메뉴에 <strong>복구 중 보관된 입력 복사</strong>가 나타납니다. 완성된 한글이 아닌 누른 키의 영문 표기로 복사되며 숫자·공백·문장부호·Shift 기호도 반영합니다. 일부 키는 키 코드로 표시될 수 있습니다. 복사하면 보관 목록을 비우고 감지를 재개합니다. 보관된 입력은 종료 시 사라지므로 한Q를 종료하기 전에 복사해 확인하세요. 복구가 중단됐는데 이 메뉴가 나타나지 않으면 한Q를 다시 실행하세요.

### 사용 조건과 알려진 제한

macOS가 한Q의 한영·한자키 기능을 중단하면 메뉴와 별도 안내창에 중단 이유를 표시합니다. 안내창을 닫아도 메뉴에서 이유를 확인할 수 있습니다. 안내창의 <strong>문제 알리기…</strong>를 누르면 보관된 기록이 있을 때 진단 기록 내보내기 창을, 기록이 없을 때 피드백 폼을 엽니다. 기록과 피드백은 직접 확인하고 제출합니다. 다시 사용하려면 메뉴에서 <strong>한영키 사용</strong> 또는 <strong>한자키 사용</strong>을 켜세요. 권한 대기나 업데이트 제한이 표시되면 먼저 해당 안내를 따르세요.

- 첫 자음 조합 보정과 한국어 입력 불일치 자동 복구는 macOS 접근성으로 본문·커서를 읽고 선택을 변경할 수 있는 입력칸에서 동작합니다. 보안 입력이나 자판 배열을 확인할 수 없는 입력기는 제외합니다.
- 다른 앱·입력칸으로 이동하거나 본문·선택 상태가 달라지면 보정을 중단할 수 있습니다. 보관된 입력을 다른 입력칸에 자동으로 보내지 않습니다.
- 두벌식의 마지막 재시도에서는 실제 자판 상태가 맞지 않거나 재입력 결과가 실패한 경우, ‘이전 입력 소스 선택’이 Control-Space로 활성화된 것을 확인한 때에만 재활성화를 한 번 시도합니다. 해당 설정을 자동으로 변경하지 않으며, 조건을 확인할 수 없으면 복구를 중단합니다.
- Safari에서는 자모 분리가 남을 수 있고, VS Code 기본 편집기에서는 본문을 읽지 못해 자동 복구가 동작하지 않을 수 있습니다. 모든 입력에서 자동 보정 성공을 보장하지 않습니다.

## 업데이트

메뉴에서 <strong>업데이트 확인…</strong>을 선택하면 새 버전이 있는지 확인할 수 있습니다. **업데이트 자동 확인**을 켜면 새 버전을 자동으로 확인하며, 설치는 사용자가 선택한 뒤 진행됩니다.

버전별 변경 사항은 [변경 이력](CHANGELOG.md)과 [GitHub 릴리스](https://github.com/jungti1234/hanq/releases)에서 확인할 수 있습니다.

중요한 보안 문제를 해결하기 위해 업데이트가 꼭 필요한 경우에는 안내와 함께 한Q 기능이 일시 중단될 수 있습니다. 이 확인은 자동 확인 설정을 꺼도 이루어집니다. 인터넷에 연결할 수 없거나 확인에 실패하면 계속 사용할 수 있습니다.

업데이트 확인 시 입력한 글자나 클립보드 내용은 전송하지 않습니다.

0.2.0의 ad-hoc 서명에서 0.3.0의 자체 서명으로 전환할 때는 손쉬운 사용 권한을 다시 허용해야 할 수 있습니다. 0.3.0부터 동일 자체 서명 인증서를 사용하며, Developer ID 서명·공증과는 다릅니다. 권한 안내가 계속되면 시스템 설정의 손쉬운 사용 목록에서 기존 한Q를 제거하고 <strong>응용 프로그램 폴더의 <code>HanQ.app</code></strong>을 다시 추가해주세요.

## 사용 중단 및 앱 제거

사용을 중단하려면 메뉴바에서 **로그인 시 자동 실행** 설정을 OFF로 변경한 뒤 **한Q 종료**를 선택하세요. 다시 앱을 실행하기 전까지 한Q의 키 매핑과 텍스트 변환 기능은 동작하지 않습니다.

앱을 제거하려면 위 절차로 종료한 뒤 다음과 같이 진행하세요.

1. Finder에서 `HanQ.app`을 휴지통으로 옮깁니다.
2. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용** 목록에 한Q가 남아 있으면 선택하고 `−` 버튼으로 제거합니다.

한Q에서 변경한 **한/A (Caps Lock) 키로 입력 소스 전환** 설정은 macOS 설정이므로 앱을 제거해도 유지됩니다. 이전 상태로 되돌리려면 앱을 종료하기 전에 해당 설정을 변경하거나, macOS의 키보드 설정에서 변경하세요.

## 문의 및 피드백

메뉴에서 **피드백 남기기…** 항목을 선택하면 브라우저에서 피드백 폼이 열립니다. 앱 버전·빌드번호, macOS 버전, Mac 모델 식별자가 미리 입력되며 내용을 작성한 뒤 직접 제출할 수 있습니다. 그 외 정보는 포함하지 않습니다.

베타 사용 중 입력 문제가 생기면 사용한 앱·한국어 입력 소스·키보드 종류(내장/외장, 모델), 누른 키와 재현 순서, 기대한 결과와 실제 결과를 함께 알려주세요. 실제 사용 환경의 피드백을 바탕으로 호환성을 개선합니다.
