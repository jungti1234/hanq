한Q 0.3.0-beta.1

입력창 밖에서 시작한 한글의 첫 자음이 분리되거나, 한국어 입력 상태인데 영문이 입력되는 현상을 자동으로 보정하는 베타 업데이트입니다.

새로 추가된 기능

첫 자음 조합 보정

  • 입력창 밖에서 타이핑을 시작할 때 ㅈㅏ처럼 첫 자음이 분리되는 현상을 자동으로 보완합니다. 쌍자음도 대상에 포함됩니다.
  • 별도 설정 없이 동작합니다.
  • 첫 자음이나 커서가 늦게 반영되면 잠시 기다려 보정 대상을 다시 확인하고, 이어서 입력한 키를 순서대로 전달합니다.
  • 두벌식에서 지연으로 분리된 첫 단어는 공백으로 확정된 뒤 입력 기록과 본문이 정확히 일치할 때 원래 입력칸에서 보완합니다. 빠른 재진입의 후속 보정도 개선했습니다.
  • 권한이나 입력 감시의 일시적인 문제가 해소되면 새 입력부터 보정을 자동으로 재개합니다.

한국어 입력 불일치 자동 복구

  • 한국어 입력 소스가 선택되어 있는데 영문이 입력되면, 현재 자판 배열에 맞게 복구하고 입력 소스를 다시 적용합니다.
  • 각 배열에서 원래 영문이 입력되는 키는 그대로 둡니다.
  • 복구 중 이어서 누른 키는 보관했다가 순서대로 전달합니다. 한Q의 우측 Command 또는 외부 키보드에 지정한 한영키로 전환한 경우에는 입력 언어가 바뀐 구간을 구분합니다.
  • 복구가 중단되어 전달하지 못한 입력이 있으면 메뉴에 복구 중 보관된 입력 복사가 나타납니다. 한Q를 종료하기 전에 복사해 내용을 확인할 수 있습니다.

개선

  • 전체 선택 후 한영 전환 시 한글 조합을 확정하고 선택을 유지하도록 개선했습니다. 이전 글자가 남거나 선택이 풀리는 현상을 보완했습니다.
  • 자동 보정·전체 선택·한영 전환·후속 입력을 순서대로 처리하도록 개선했습니다.
  • 입력칸을 교체한 뒤 첫 한영 전환이 실패하던 문제를 수정했습니다.
  • 앱의 응답 지연 중 다른 앱으로 이동할 때 원래 입력한 키가 새 앱에 들어가는 문제를 보완했습니다.
  • Spotlight의 입력칸 추적과 주소창 자동 완성·자동 영문 대문자화·선택 반영 지연의 처리도 개선했습니다.
  • 선택 영타 변환에 로마자 입력기의 자판 배열과 모음·자음 조합 규칙을 반영했습니다.

내부 정리

사용 조건과 알려진 제한

  • 한Q의 지원 대상은 Apple 공식 한국어 입력기 전체입니다. 실제 키보드·앱·macOS 환경에서의 동작은 베타 사용자 피드백을 받아 개선합니다.

  • 두 자동 보정 기능은 macOS 접근성으로 글자·커서 위치를 확인하고 선택을 변경할 수 있는 입력칸에서 동작합니다. 보안 입력이나 자판 배열을 확인할 수 없는 입력기는 대상에서 제외됩니다.

  • 다른 앱이나 입력칸으로 이동하거나 본문·선택 상태가 달라지면 보정을 중단할 수 있습니다. 남은 입력을 다른 입력칸에 자동으로 보내지 않습니다.

  • 첫 자음 보정은 모든 입력에서 자모 분리를 해결하지는 못합니다. Safari에서는 자모 분리가 남을 수 있고, VS Code 기본 편집기에서는 본문을 읽지 못해 자동 복구가 동작하지 않을 수 있습니다.

  • 한국어 입력 불일치 복구에는 macOS의 Control-Space 입력 소스 전환 단축키가 활성화되어 있어야 합니다. 복구 도중 Caps Lock이나 메뉴바로 언어를 전환한 구간의 추적은 아직 지원하지 않습니다.

  • 보관된 입력 복사 메뉴는 한국어 입력 불일치 복구에서 남은 입력에 적용됩니다. 완성된 한글이 아닌 누른 키의 영문 표기로 복사되며, 일부 키는 키 코드로 표시될 수 있습니다. 복사하면 보관 목록을 비우고 감지를 재개하며, 한Q를 종료하면 보관 내용은 사라집니다.

  • 한국어 입력 불일치 복구가 중단됐는데 보관된 입력 복사 메뉴가 나타나지 않으면 한Q를 다시 실행해 주세요.

업데이트 및 설치

  • 기존 사용자는 한Q 메뉴의 업데이트 확인…으로 설치할 수 있습니다. 업데이트 자동 확인이 켜져 있으면 새 버전을 자동으로 확인하며, 설치는 사용자 선택 후 진행합니다.
  • 새로 설치할 때는 릴리스의 Assets에서 .dmg 파일을 받아 열고 HanQ.app을 Applications(응용 프로그램) 폴더로 복사하세요.
  • Apple Silicon Mac, macOS 13.0 이상 대상이며 손쉬운 사용 권한이 필요합니다. 모든 macOS 버전·앱에서의 동작을 보장하는 것은 아닙니다.
  • 이 베타는 동일 자체 서명 인증서를 사용합니다. Developer ID 서명·공증은 미적용입니다. 출처를 확인한 설치 파일의 최초 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 선택하세요.
  • 기존 0.2.0에서 업데이트하면 서명 방식 변경으로 손쉬운 사용 권한을 다시 허용해야 할 수 있습니다. 권한 안내가 계속되면 시스템 설정의 손쉬운 사용 목록에서 기존 한Q를 제거하고, 응용 프로그램 폴더의 HanQ.app을 다시 추가하세요.

자세한 사용법은 README, 문제 제보는 앱 메뉴의 피드백 남기기…를 이용하세요. 사용 앱·입력 소스·키보드 종류와 함께 재현 순서, 기대한 결과와 실제 결과를 알려주시면 확인에 도움이 됩니다.
