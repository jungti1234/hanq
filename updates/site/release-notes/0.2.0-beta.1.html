한Q 0.2.0-beta.1

외부 키보드에서도 익숙한 키로 한영 전환과 한자 입력을 사용할 수 있어요.

외부 키보드 설정

  • 처음 감지한 외부 키보드에서 한영키·한자키를 차례로 눌러 저장하세요. 기기별로 기억하고 내장 키보드는 기존 설정을 유지합니다.
  • 외부 키보드가 연결되면 메뉴바에 외부 키보드 설정이 나타나며 언제든 다시 지정할 수 있습니다.
  • 다른 창을 클릭해도 설정 진행을 유지합니다. 나중에 설정하려면 안내를 확인한 뒤 창을 닫을 수 있습니다.
  • 오른쪽 보조키·언어키·메뉴 키를 지원하며 왼쪽 보조키와 일반 입력 키의 오등록을 막습니다.

설치 안내

Apple Silicon · macOS 13.0 이상. 이 베타는 Developer ID 서명·공증 미적용입니다.

업데이트 후 손쉬운 사용 권한을 다시 허용해야 할 수 있습니다. 권한 안내가 계속되면 시스템 설정에서 기존 한Q 항목을 제거하고 응용 프로그램 폴더의 HanQ.app을 다시 추가해주세요.
