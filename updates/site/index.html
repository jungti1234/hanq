Apple Silicon · macOS 13 이상

  1. 01

    다운로드하고

    릴리스 페이지의 Assets에서 .dmg 파일을 내려받으세요.

  2. 02

    응용 프로그램에 넣고

    DMG를 열고 HanQ.app을 Applications 폴더로 복사한 뒤 실행하세요.

  3. 03

    손쉬운 사용을 허용하면

    시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 한Q를 허용하세요.

BETA NOTE

첫 실행 전에 확인해주세요.

현재 베타는 Developer ID 서명·공증이 적용되지 않았어요. 실행이 차단되면 출처를 확인한 설치 파일에 한해 시스템 설정 → 개인정보 보호 및 보안에서 ‘그래도 열기’를 선택해주세요. 업데이트 후 손쉬운 사용 권한을 다시 허용해야 할 수 있어요.
