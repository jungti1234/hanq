# 한Q 0.1.0-beta.1

한Q 첫 공개 베타.

## 주요 기능

- 우측 Command로 한영 전환, 전환한 입력 소스 이름 표시.
- 우측 Option으로 한자 변환·선택한 영타의 한글 변환·분리된 자모 합치기.
- macOS 기본 입력기를 유지하며 한/A (Caps Lock) 키 전환 설정과 로그인 시 자동 실행 제공.
- 메뉴에서 업데이트 확인 및 업데이트 자동 확인 설정 제공. 설치는 사용자 확인 후 진행.

## 설치 및 지원 환경

- Apple Silicon Mac, macOS 13.0 이상 대상. 실제 실행 확인 환경은 macOS 15.7.9.
- 아래 Assets의 `.dmg` 파일을 열고 `HanQ.app`을 **Applications(응용 프로그램)** 폴더로 복사한 뒤 실행.
- 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 한Q 허용 필요.
- `Source code (zip)`과 `Source code (tar.gz)`는 설치용 앱이 아닌 소스 코드.

## 알려진 제한

- 이 버전은 Developer ID 서명·공증 미적용. 정식 출시 전 베타 단계에서 적용 예정. macOS 보안 설정에 따라 최초 실행이 차단될 수 있음.
- 편집기의 접근성 지원과 입력 상태에 따라 텍스트 변환·한자 처리·실행 취소 동작에 차이 있음.
- 최소 지원 버전 설정이 모든 macOS 환경의 검증 완료를 의미하지 않음.
