# 한Q 0.2.0-beta.1

외부 키보드의 한영키·한자키를 직접 지정할 수 있는 베타 업데이트입니다.

## 달라진 점

- 처음 연결한 미설정 외부 키보드에서 한영키·한자키를 차례로 누르고 저장하면 기기별 설정을 기억합니다. 내장 키보드는 기존 우측 Command·Option을 사용합니다.
- 외부 키보드가 연결된 동안 메뉴바의 **외부 키보드 설정**에서 키를 다시 지정할 수 있습니다.
- 설정 중 다른 창을 클릭해도 진행 상태를 유지합니다. **나중에**를 누르면 안내를 확인한 뒤 설정을 계속하거나 창을 닫을 수 있습니다.
- 오른쪽 보조키·언어키·메뉴 키를 등록할 수 있으며 왼쪽 보조키와 일반 입력 키의 오등록을 막습니다.
- 한Q 로고와 단계별 안내를 적용하고 한영키·한자키 표기를 정리했습니다.

## 업데이트 및 설치

- 기존 사용자는 한Q 메뉴의 <strong>업데이트 확인…</strong>으로 설치할 수 있습니다. **업데이트 자동 확인**이 켜져 있으면 새 버전을 자동으로 확인하며 설치는 사용자 선택 후 진행합니다.
- 새로 설치할 때는 아래 Assets의 `.dmg` 파일을 열어 `HanQ.app`을 **Applications(응용 프로그램)** 폴더로 복사하세요.
- Apple Silicon Mac, macOS 13.0 이상 대상입니다. 손쉬운 사용 권한이 필요합니다.
- 이 베타는 Developer ID 서명·공증 미적용입니다. 처음 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 선택하세요.
- 업데이트 후 손쉬운 사용 권한 안내가 계속되면 기존 한Q 항목을 제거하고 응용 프로그램 폴더의 `HanQ.app`을 다시 추가하세요.

## 사용 안내

- 키는 macOS가 전달한 신호를 기준으로 구분합니다. F키·Caps Lock·Fn·조합 키는 등록할 수 없습니다.
- 연결 방식·포트 변경 시 다시 등록할 수 있습니다. 일련번호 없는 같은 모델을 같은 포트에 번갈아 연결하면 기존 설정을 공유할 수 있습니다.
- 다른 키 매핑 도구나 기기 특성 때문에 입력 출처를 구분할 수 없으면 등록·매핑이 제한될 수 있습니다.

자세한 사용법은 [README](https://github.com/jungti1234/hanq#readme), 문제 제보는 앱 메뉴의 <strong>피드백 남기기…</strong>를 이용하세요.
