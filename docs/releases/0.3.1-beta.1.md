# 한Q 0.3.1-beta.1

> 미배포 초안입니다. 현재 공개된 다운로드는 0.3.0-beta.1이며, 아래 변경은 다음 업데이트에 포함될 예정입니다.

한자 후보의 표시와 확정을 개선하고, 입력창 진입·전체 선택·한영 전환과 메뉴바 아이콘의 안정성을 보완하는 베타 업데이트입니다.

## 한자 입력 개선

- 한자 후보에서 원문 한글 항목을 제외합니다. 기본 사전과 사용자 등록 사전을 함께 확인하며, 사용자 등록 변환 문구도 유지합니다.
- 원문과 다른 후보가 없으면 후보창을 열지 않습니다. 조회에 실패하거나 후보창을 표시할 수 없으면 기존 Apple 입력기의 후보창을 사용합니다.
- 숫자 1–9, 방향키와 Return, 마우스로 후보를 선택할 수 있습니다. 후보가 많으면 Page Up/Down으로 이동하며 Escape로 취소합니다.
- 한글 조합 직후 한자를 선택했는데 원문이 그대로 남거나 글자가 중복되는 문제를 수정했습니다.
- 후보창이 화면 모서리에 뜨거나 적은 후보 아래에 큰 빈 공간이 남는 문제를 보완했습니다.

## 입력·선택 안정성 개선

- 한국어 입력 불일치의 기본 복구는 시스템 전환 단축키 없이 입력 소스를 직접 선택합니다. 복구 중 Caps Lock·메뉴바로 바꾼 언어를 후속 입력에 반영하고, 메뉴를 취소해도 기존 언어에서 복구를 이어갑니다.
- 재입력 뒤 한글·분리 자모·영문이 섞여 남거나 후속 한글 조합이 끊기는 경우의 복구를 보완했습니다. 실제 입력 이력과 본문·커서가 확인된 구간에만 적용합니다.
- 두벌식의 마지막 재시도에서 실제 자판 상태가 맞지 않거나 재입력 결과가 실패하면, ‘이전 입력 소스 선택’이 Control-Space로 활성화된 것을 확인한 경우에만 재활성화를 한 번 시도합니다. 설정을 변경하지 않으며, 조건을 확인할 수 없으면 기존 안전 중단을 유지합니다.
- 유휴 상태에서 자동 복구 감시가 중단되면 제한된 횟수로 다시 등록합니다. 진행 중인 복구나 보관된 입력이 있는 중단은 자동으로 재개하지 않습니다.
- 지연으로 분리된 첫 단어를 공백으로 확정한 뒤 보완하는 동작을 다섯 한국어 입력기에 적용했습니다. 세벌식의 숫자·문장부호·Shift 키와 로마자 조합 규칙을 따릅니다.
- 입력창을 먼저 클릭하지 않고 타이핑을 시작할 때 첫 자음 보정을 개선했습니다. 기존 글자·공백·선택을 보존하고 입력창 안내 문구가 사라지는 경우도 처리합니다.
- 텍스트 선택을 제공하는 콤보 상자 입력란에서도 첫 자음 보정·전체 선택·선택 유지 한영 전환을 지원합니다.
- 첫 자음 보정 직후 전체 선택하거나 한영을 전환할 때 선택이 풀리거나 후속 입력이 지연되는 문제를 보완했습니다.
- 전체 선택 시 안내 문구가 사라지는 경우와 커서·선택 반영이 늦는 경우에도 앞선 입력과 후속 키의 순서를 확인합니다.

## 메뉴바 아이콘 복구와 안내

- 메뉴바 항목의 표시·이미지·등록 누락을 자동 복구하고, 화면 구성 변경·잠자기 복귀에 다시 등록합니다.
- 한Q가 실행 중이어도 앱을 다시 열면 메뉴바 아이콘을 재등록해 복구를 시도합니다. 기존 메뉴와 저장된 아이콘 위치를 유지합니다.
- 60초 안에 다시 열기를 3회 시도하면 <strong>한Q - 메뉴바 아이콘 안내</strong> 창이 나타납니다. 노치·메뉴바 공간·숨김 설정을 확인하고, 문제가 계속되면 <strong>피드백 남기기…</strong> 버튼으로 제보할 수 있습니다.

## 사용 조건과 알려진 제한

- Apple 공식 한국어 입력기인 두벌식·세벌식·세벌식 390·공진청 로마자·한컴 로마자가 지원 대상입니다.
- 한자 변환과 자동 보정은 현재 입력칸의 접근성 지원과 입력 상태에 따라 동작합니다. 보안 입력, 대상 입력칸 변경, 본문·선택 변경 시 작업을 중단할 수 있습니다.
- 기존 후보창으로 복귀한 경우에는 원문 한글 항목 등 Apple 입력기의 기존 동작이 나타날 수 있습니다.
- 한자 변환의 실행 취소는 편집기마다 다르며, 한 번의 Undo로 원문 복원을 보장하지 않습니다.
- Safari의 자모 분리와 VS Code 기본 편집기의 본문 조회 제한은 남아 있습니다. 모든 macOS·앱·키보드 환경에서의 동작을 보장하지 않습니다.
- 전환 의도나 입력 상태를 확인할 수 없으면 복구를 중단합니다.
- macOS나 메뉴바 관리 앱이 아이콘을 숨기는 경우에는 해당 표시·숨김 설정을 직접 확인해야 합니다. 모든 원인의 메뉴바 아이콘 누락을 자동으로 복구하지는 못합니다.

## 업데이트 및 설치

- 이 초안의 버전은 아직 다운로드하거나 앱에서 업데이트할 수 없습니다. 공개 후 기존 사용자는 한Q 메뉴의 <strong>업데이트 확인…</strong>으로 설치할 수 있습니다.
- 새로 설치할 때는 공개 릴리스의 Assets에서 `.dmg` 파일을 받아 열고 `HanQ.app`을 Applications(응용 프로그램) 폴더로 복사하세요.
- Apple Silicon Mac, macOS 13.0 이상 대상이며 손쉬운 사용 권한이 필요합니다.
- 이 베타는 기존 0.3.0과 동일한 자체 서명 인증서를 사용합니다. Developer ID 서명·공증은 미적용이며, 정식 출시 시 적용할 예정입니다. 최초 실행이 차단되면 출처를 확인한 설치 파일에 한해 시스템 설정 → 개인정보 보호 및 보안에서 <strong>그래도 열기</strong>를 선택하세요.
- 동일 인증서 업데이트에서도 환경에 따라 손쉬운 사용 권한 재승인이 필요할 수 있습니다. 기존 0.2.0의 ad-hoc 서명 앱에서 전환하는 경우에는 재승인이 필요할 수 있습니다. 권한 안내가 계속되면 기존 한Q 항목을 제거하고 응용 프로그램 폴더의 `HanQ.app`을 다시 추가하세요.

자세한 사용법과 기존 자동 보정의 적용 조건은 [README](https://github.com/jungti1234/hanq#readme)를 참고하세요. 문제 제보는 앱 메뉴의 <strong>피드백 남기기…</strong>를 이용하고, 사용 앱·입력 소스·키보드 종류와 재현 순서·기대 결과·실제 결과를 함께 알려주세요.
